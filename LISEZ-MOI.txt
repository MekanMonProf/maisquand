MAIS QUAND ? · Mise en ligne de maisquand.com
==============================================

CONTENU DU DOSSIER
------------------
index.html            La page du site (tout le site est dans ce fichier)
images/               Photos, vidéo et image de partage (partage.jpg)
favicon.svg           Icône de l'onglet du navigateur
apple-touch-icon.png  Icône quand on ajoute le site à l'écran d'accueil d'un téléphone
robots.txt            Autorise Google à référencer le site
sitemap.xml           Plan du site pour Google
LISEZ-MOI.txt         Ce mode d'emploi (il n'est pas nécessaire en ligne)

Important : gardez cette organisation. index.html doit rester à la racine,
à côté du dossier images/.


HÉBERGEMENT : GITHUB PAGES (gratuit, sans crédits)
=================================================
Le site est publié par GitHub Pages à partir de la branche main du dépôt
github.com/MekanMonProf/maisquand. Netlify n'est plus utilisé : son offre
gratuite suspendait les mises en ligne une fois les crédits épuisés.

Deux fichiers servent à GitHub Pages, ne les supprimez pas :
CNAME       Le nom de domaine du site (maisquand.com)
.nojekyll   Demande à GitHub de publier les fichiers tels quels


ÉTAPE 1 · Activer GitHub Pages (une seule fois)
-----------------------------------------------
1. Connectez-vous à GitHub (bouton « Sign in », pas « Sign up »).
2. Ouvrez https://github.com/MekanMonProf/maisquand/settings/pages
3. « Source » : choisissez « GitHub Actions ». Le site est alors
   publié par le fichier .github/workflows/pages.yml, qui crée aussi
   une vraie page par article (voir ÉTAPE 3).
4. « Custom domain » : vérifiez que maisquand.com est inscrit
   (sinon, saisissez-le et cliquez sur « Save »).
Après une minute, le site répond aussi à l'adresse
https://mekanmonprof.github.io/maisquand/ (avant le changement de DNS,
cette adresse peut renvoyer vers maisquand.com).


ÉTAPE 2 · Faire pointer maisquand.com vers GitHub
-------------------------------------------------
Les enregistrements DNS se modifient là où ils sont gérés aujourd'hui :
- si vous aviez choisi « Netlify DNS » : dans Netlify, « Domains »
  > maisquand.com > « DNS settings » (ou remettez les serveurs DNS
  d'origine chez votre registraire et faites la suite chez lui) ;
- sinon : chez le registraire où vous avez acheté maisquand.com.

Supprimez les anciens enregistrements A et CNAME qui pointent vers
Netlify, puis ajoutez :

  Type   Nom                 Valeur
  A      maisquand.com (@)   185.199.108.153
  A      maisquand.com (@)   185.199.109.153
  A      maisquand.com (@)   185.199.110.153
  A      maisquand.com (@)   185.199.111.153
  CNAME  www                 mekanmonprof.github.io

Patientez : la bascule prend de quelques minutes à 24 heures.
Revenez ensuite sur la page de l'étape 1 : quand GitHub indique que le
DNS est correct, cochez « Enforce HTTPS » (le cadenas).

Une fois maisquand.com servi par GitHub, vous pouvez supprimer le
projet dans Netlify.


ÉTAPE 3 · Mettre à jour le site
-------------------------------
Toute modification fusionnée dans la branche main (ou enregistrée depuis
l'administration) est publiée automatiquement en une à deux minutes.
Si la page ne change pas, rechargez-la avec Ctrl + F5.

À chaque publication, le programme outils/pages.mjs crée une vraie page
pour chaque article (maisquand.com/a/…), chaque vérification
(maisquand.com/v/…) et chaque date (maisquand.com/d/…), avec son titre,
son résumé et sa photo : ce sont ces adresses que Google référence et
que WhatsApp affiche avec un aperçu. Il met aussi à jour le plan du
site (sitemap.xml). Le bouton « Partager » des articles utilise ces
adresses ; les anciennes adresses en # fonctionnent toujours.
Suivi des publications : https://github.com/MekanMonProf/maisquand/actions
(une coche verte = en ligne ; une croix rouge = échec, rien n'a changé
sur le site).


ÉTAPE 4 · Publier un article vous-même
--------------------------------------
Tout se gère depuis l'espace d'administration :
https://maisquand.com/admin/
Il regroupe les pages Articles (écrire et publier un article sans
toucher au code), Vrai ou faux ? (les rumeurs vérifiées), Dates
« Mais quand ? » et Partenaires. Il n'est lié nulle part sur le site et Google ne
le référence pas. Les anciennes adresses (redaction.html,
verifications.html) renvoient automatiquement vers les nouvelles.

Une seule fois, créez votre clé GitHub (5 minutes) :
1. Connecté à GitHub, ouvrez
   https://github.com/settings/personal-access-tokens/new
2. « Token name » : Rédaction Mais quand
   « Expiration » : 1 an (notez la date : il faudra en créer une
   nouvelle à l'expiration).
3. « Repository access » : « Only select repositories », puis
   choisissez MekanMonProf/maisquand.
4. « Permissions » > « Repository permissions » > « Contents » :
   « Read and write ». Ne cochez rien d'autre.
5. « Generate token », puis copiez la clé (elle commence par
   github_pat_). GitHub ne la montre qu'une fois.
6. Sur la page Articles de l'espace d'administration, collez-la et cliquez sur « Se connecter ».
   La clé reste enregistrée sur cet appareil ; « Se déconnecter »
   l'efface.

Ne donnez jamais cette clé à personne et ne la collez pas ailleurs.
Si vous pensez qu'elle a fuité, supprimez-la sur
https://github.com/settings/personal-access-tokens puis créez-en une
nouvelle.

Pour publier :
- remplissez le titre, le chapô, la catégorie et le texte (une ligne
  vide entre deux paragraphes) ; la photo, les encadrés « Ce qu'on
  sait » et les sources sont facultatifs ;
- vidéos : jusqu'à 3 par article, au format MP4, 25 Mo maximum
  chacune (une vidéo envoyée par WhatsApp est déjà compressée et
  convient). Elles s'affichent sous le texte. En modification, les
  vidéos déjà en ligne sont gardées et les nouvelles s'ajoutent ;
- « Aperçu » montre l'article avant publication ;
- « Publier » le met en ligne une à deux minutes plus tard. La case
  « Mettre à la une » (cochée par défaut) le place en grand en haut de
  l'accueil ; décochée, l'article est publié juste en dessous et la une
  actuelle ne bouge pas. En modification, la case « Remettre cet article
  à la une » fait remonter un article publié plus tôt.
- « Rappel du jour le … » : cochez la case et choisissez une date. Ce
  jour-là (heure de Dakar), l'article s'affiche dans le grand bandeau
  vert « Le rappel du jour », puis il revient dans la liste. Une seule
  date par article ; si un autre article était déjà prévu ce jour-là,
  il est libéré.
- « Tous les articles » liste tous les articles du site, dans l'ordre
  de l'accueil, avec une recherche. Le rappel du jour ne peut qu'être
  retiré. Les éléments que le formulaire n'affiche pas (liens de
  sources, conseils, lien vers une date « Mais quand ? »…) sont
  conservés lors d'une modification.
  « Modifier » remplit le formulaire avec l'article : corrigez, puis
  « Enregistrer les modifications ». L'adresse de l'article ne change
  pas ; sans nouvelle photo, l'ancienne est gardée. La case « Afficher
  mis à jour le … » ajoute cette mention sous l'article (décochez-la
  pour une simple faute de frappe).
  « Retirer » enlève un article du site en cas d'erreur.

Pour les rumeurs (rubrique « Vrai ou faux ? ») : ouvrez
https://maisquand.com/admin/verifications.html (ou la tuile « Vrai ou
faux ? » de l'administration). Même clé, même fonctionnement :
- écrivez la rumeur telle qu'elle circule, choisissez le verdict (Faux,
  Trompeur, Vrai, Non vérifié), puis remplissez « Ce qui circule »,
  les preuves (une par ligne), la conclusion, le bon réflexe et les
  sources (une par ligne, avec le lien https://… à la fin de la ligne) ;
- « Mettre en tête » (cochée par défaut) place la vérification en
  premier ; les 3 premières s'affichent sur la page d'accueil.
  Décochée, elle se place juste après ces trois-là ;
- « Toutes les vérifications » permet de les modifier ou de les retirer.

Pour les dates de la rubrique « Mais quand ? » : page Dates de
l'administration (https://maisquand.com/admin/dates.html).
- la question (« Quand… ? »), la date attendue, la catégorie, la
  fiabilité (élevée, moyenne, faible) et sa précision, les sources ;
- « Nouvelle information » s'ajoute en haut de l'historique avec la
  date du jour (ex. : « Date confirmée par le ministère ») ;
- une date passée est signalée dans la liste : « Résolue » demande la
  réponse finale et la range dans « Résolues récemment ».

Pour les partenaires : page Partenaires de l'administration.
- nom, adresse, phrase de présentation, logo (réduit automatiquement),
  couleur du nom ; les flèches ↑ ↓ changent l'ordre d'affichage ;
- en bas, « Contact pour les annonceurs » : le numéro WhatsApp et
  l'e-mail affichés sur la page « Annoncer chez nous ».


À VÉRIFIER AVANT D'ANNONCER LE SITE
-----------------------------------
- Le rappel du jour est daté du vendredi 9 octobre : pensez à le mettre
  à jour, ou à le retirer s'il n'est pas actualisé chaque jour.
- L'article sur la conférence de presse attend encore le nom de
  l'intervenante, de l'organisation et du lieu.
- Les dates « approximatives » et « estimées » de la rubrique Mais quand ?
  doivent être remplacées dès que les dates officielles sont publiées.
- Testez l'aperçu de partage : envoyez le lien https://maisquand.com
  dans une discussion WhatsApp. Le titre, la description et l'image
  partage.jpg doivent s'afficher.
- Les attentes suivies (« + Suivre ») sont enregistrées sur l'appareil
  de chaque lecteur. Les alertes automatiques demanderont plus tard un
  serveur.
